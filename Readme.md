## Лабораторная работа №3 — основы JavaScript

**Цель:** изучение основ JavaScript.

**Задание:** реализовать функции из `lab3/src/core.js` по каркасу [js-tasks](https://github.com/teach-kirshdv/js-tasks) так, чтобы проходили тесты.

**Как запустить:**
```
cd lab3
npm install
npm test
```

**Что сделано:**
- `isInteger` — проверка на целое через `n | 0`
- `even` — чётные от 2 до 20, цикл с шагом 2
- `sumTo` — сумма от 1 до n, цикл
- `recSumTo` — та же сумма, рекурсия
- `factorial` — факториал, цикл
- `isBinary` — степень двойки: делим на 2, пока делится, цикл
- `fibonacci` — n-е число Фибоначчи, цикл
- `getOperationFn` — копит значение между вызовами, замыкание
- `sequence` — генератор арифметической прогрессии, замыкание
- `deepEqual` — глубокое сравнение, рекурсия

**Особенности реализации:**
- `isInteger` — по ТЗ «используя побитовые операторы», а они работают с int32, поэтому верно только в диапазоне ±2^31
- `isBinary` — делением на 2, а не `n & (n - 1)`: побитовый вариант ошибается на дробных и больших числах; степень считаю целой неотрицательной (тест `isBinary(1) === true`)
- `sequence` — «функция генератор» сделана замыканием: «каждый вызов функции генератора возвращает следующий элемент последовательности»
- `deepEqual` — значения сравниваются как в Set/Map: NaN равен NaN
- `deepEqual` — «Учитывать специфичные объекты(такие как Date, RegExp и т.п.) не обязательно», поэтому они не учитываются
